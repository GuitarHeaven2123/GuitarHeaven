# GuitarHeaven

Catalogo musical desarrollado con React y Vite. Permite explorar instrumentos y accesorios, filtrar y ordenar productos, consultar ofertas, buscar tiendas en Guadalajara y administrar un carrito.

## Tecnologias

- React
- Vite
- JavaScript
- CSS

## Funcionalidades

- Catalogo completo con busqueda, filtros y paginacion
- Productos destacados por categoria
- Ofertas con calculo de descuentos y ahorros
- Informacion de tiendas fisicas y enlaces de compra en linea
- Carrito de productos
- Quiz para descubrir el instrumento recomendado
- Seccion de resenas y tiendas

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilacion

```bash
npm run build
```
